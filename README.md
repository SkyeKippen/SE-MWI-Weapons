**Naming Scheme:**\
SKC_01_Mk1 "Common Name"
S - Small (Size)\
K - Kinetic (Damage Type (kinetic/Energy))\
C - Cannon (Weapon Style/Type)\
01, 02, 03... - Iterates with each new weapon design regardless of prefix\
Mk1 - Mk1, Mk2, Mk3 - Specifically for the same style/design of weapon, each Mk# up is generally a straight upgrade

**Size Guidelines:**\
T - Tiny (1x1x1)\
S - Small (Up to 3x3x3)\
M - Medium (Up to 5x5x5)\
L - Large (Up to 7x7x7)\
X - X-Large (Up to 9x9x9)\
C - Capital/Super Weapon (Anything larger)\
